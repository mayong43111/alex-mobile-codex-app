# 云端运行补充

本文资源名、域名、UUID、路径与网络地址已替换为示例或占位符，不是可直接使用的现网配置。

新增 PWA 安装清单、PNG 图标及不保存响应的 Service Worker。云端素材改用系统托管身份访问私有 Blob；聊天数据库和运行时检查点仍保存在 Web App 持久目录。启动时迁移已有素材并保留旧文件回退，详见部署记录。以下本地磁盘存储说明仅适用于本地开发模式。

云端使用应用内会话认证，支持 Microsoft Entra ID 和管理员创建的本地账号密码，不再依赖 Web App Easy Auth 或 `x-ms-client-principal` 身份头。GPT/image 继续使用系统托管身份。详见 [云端部署记录](../docs/WEBAPP-deployment.md)。以下无认证说明只适用于回环地址的本地开发模式。

## 登录与用户隔离

- Entra 使用官方 `@azure/msal-node` 的服务端授权码流程，包含 PKCE、一次性 state、nonce 和浏览器绑定；回调为 `/api/auth/callback`。仅允许配置租户及 `ENTRA_ALLOWED_USER_IDS` 内用户，保留企业应用用户分配要求。客户端密钥只在服务端，登录令牌不传给 Codex。
- 本地密码使用 Argon2id 哈希，关闭公开注册。`ENTRA_ADMIN_USER_IDS` 是获准 Entra 用户的子集；管理员登录后在“设置 / 本地账号管理”创建账号或明确重置密码。密码至少 12 字符，账号为 3 至 64 个小写字母、数字、点、下划线或连字符，以字母或数字开头。重置会撤销该本地账号的所有会话，不改变其项目归属。不要把密码发到聊天或提交到仓库。
- Cookie 为 HTTPS 下的 `__Host-`、HttpOnly、Secure、SameSite=Lax；服务端仅保存随机会话令牌哈希，固定 12 小时过期。写操作验证精确 Origin 和 CSRF token，密码登录有全局限速。适用于 1 至 2 人低频单实例使用，不是分布式身份平台；不提供公开注册、邮箱找回或自动账号合并。
- Entra 使用租户 ID + 对象 ID 标识，本地账号使用独立 UUID；同名或同邮箱不会自动合并。两个入口登录同一个人也可能得到不同工作区。
- 项目列表、对话、重发、上传下载、缩略图、视频 Range、任务操作及 SSE 均由服务端校验项目所有者；越权 ID 返回 404。管理员权限不绕过项目所有权。既有共享项目保留但无所有者，默认不向任何新账号展示，不自动分配或删除。
- Codex 继续按项目使用独立 thread 和工作目录；候选素材及对话只来自该项目。模型凭据、执行进程和 GPU 仍共享，全局串行队列适用于低频使用，不为每个用户启单独容器，也不强制新建模型账户。
- 本地默认无认证，仅限回环地址；需要验证本地密码登录可设置 `AUTH_ORIGIN=http://127.0.0.1:5188` 并使用独立测试数据目录。生产必须配置 `WEBSITE_HOSTNAME`、`ENTRA_TENANT_ID`、`ENTRA_CLIENT_ID`、`ENTRA_CLIENT_SECRET`、`ENTRA_ALLOWED_USER_IDS`，缺失时拒绝启动。管理员可选配置 `ENTRA_ADMIN_USER_IDS`。

助手正文使用 Markdown/GFM 渲染，支持标题、列表、引用、表格及代码块。禁用原始 HTML 和回复内外部图片自动加载；长表格/代码块在手机内横向滚动。复制保留原始 Markdown，Process 仍展示 SDK 原文。

进入或切换项目会话自动定位最新消息。位于底部时跟随回复、媒体尺寸和可视区域变化；向上阅读历史时暂停跟随，回到底部或发送新消息后恢复。停止回复及任务记录中的停止运行按钮使用红色实心方块。


# Codex Studio 本地工作台

React 19 + TypeScript + Vite，Fastify + SQLite。面向低频多用户的纯手机界面；已接入真实 Codex 对话及 Azure image2 单图生成，启动本身不创建或启动云资源。

## 启动

使用 Node.js 22.23.2。当前开发机的隔离安装路径如下；其他机器使用自己的 Node 22 环境即可。

```bash
export PATH="$HOME/.local/share/node-v22.23.2-linux-x64/bin:$PATH"
cd /path/to/alex-mobile-codex-app/app
npm ci
WEB_PORT=5188 API_PORT=3188 APP_ORIGINS=http://127.0.0.1:5188,http://localhost:5188 npm run dev
```

打开 <http://localhost:5188>。当前开发机的默认 5173 端口已占用，因此使用 5188；不要停止不属于本项目的服务。若 5188 也被占用，选择其他空闲端口，并同步修改 `WEB_PORT`、`API_PORT` 和 `APP_ORIGINS`。

默认 `npm run dev` 使用网页 5173 / API 3001。前端通过 `/api` 代理到后端。两个进程仅监听 `127.0.0.1`；Ctrl+C 同时停止它们。

远程 VS Code 中，在“端口”面板将远端 **5188** 私有转发到本机，再打开对应的本机 URL。不需要转发 API 端口，不要配置公开端口或放开 NSG。如果本机映射端口改变，需要把新的精确 Origin 加入 `APP_ORIGINS` 并重启。手机布局已在浏览器模拟器验证，真实手机远程访问仍需后续的认证和 HTTPS 部署。

## Codex 与 OpenMontage

### 四个创作入口

项目首页提供“做图片”“修改图片”“做短镜头”“写脚本分镜”四个入口；已有对话可点击输入框下方工具栏的“创作引导”图标唤起，不占用项目列表空间。选择入口后打开对应需求表单：

- 做图片：填写画面内容、风格与用途。
- 修改图片：明确选择项目原图或上传 PNG/JPEG/WebP，填写修改要求与需保留的内容；不默认选最新图片。指定原图 ID 写入草稿并附加该素材，保留已有附件，不覆盖原图。
- 做短镜头：填写镜头内容、动作与运镜；显示 MiniMax H3 当前状态，模型须用户显式选择，未就绪时不能新启用，不自动启动 GPU 或换服务。
- 写脚本分镜：填写主题、受众、时长和重点；草稿明确要求镜号、时长、画面、运镜、旁白及字幕，仅编写文字方案。

“带入草稿”只将需求追加至现有草稿，不调用模型或生成媒体；没有项目时创建项目，上传原图仅保存素材。取消表单不改变草稿和附件。仍须在输入框主动发送，沿用现有 `auto`/Codex 决策和服务可用性规则；入口不是新的固定后端生成模式，也不代表完整 OpenMontage 多阶段流水线已经接通。脚本只输出文字是交给 Codex 的明确指令，不是新增服务端执行沙箱。

弹层共用紧凑标题栏、固定关闭按钮、44 像素触控控件及 16 像素表单字号；长内容在右侧滚动。项目、设置、服务、素材、任务、创作引导及媒体预览沿用同一套边距和字段样式，320/390 像素布局回归均通过。数字人口播直接在对话中完成，不使用独立制作表单。

图片、文件与视频下载保留原页面；浏览器不支持直接下载时在独立窗口打开，隔离 `opener`。真实手机系统或 PWA 的保存交互仍需实机确认。实际发布状态见 [部署记录](../docs/WEBAPP-deployment.md)。

图片、文件及视频预览新增“转发”，对话视频和数字人口播记录也可直接转发。首次点击通过既有鉴权接口读取文件，准备完成后点击“选择转发应用”调用系统 Web Share 文件分享，确保分享调用发生在新的用户手势中。分享的是完整文件，不是需登录的私有素材地址；上传图片按实际归一化后的 PNG 文件名和 MIME 转发。准备可取消，关闭预览会中断读取；用户关闭系统分享面板不视为失败，也不离开会话。

文件转发需要 HTTPS 安全环境（本地回环地址可用于开发）和支持 `navigator.share` / `navigator.canShare({ files })` 的浏览器；文件类型、大小及可接收应用由系统决定，应用侧上限为 64 MiB。不支持时明确提示，不退回链接分享，不创建公开地址。转发后的副本由接收应用管理，不再受本项目访问权限控制。手机模拟已验证文件字节、名称、类型、取消和失败处理；系统分享面板及微信等实际接收应用仍需真机验收。

### 对话式连续口播

项目首页、输入区创作引导或项目菜单的“数字人口播”只准备对话草稿，不打开独立工具、不覆盖已有草稿、不自动提交。文案讨论、主播原图选择、声音和续接安排均在普通对话中确认；用户明确要求执行后，Codex 输出结构化口播计划，由应用交接给原生任务。原图必须明确指定，未配置或信息不足时应先回复说明，不自动选择最新图片或替换生成服务。

每次支持 1–12 段，每段 1–100 个 UTF-16 代码单元、合计最多 500，声音为普通话晓晓或云希。文案作为纯文本传给原生 `AzureTTS`，不执行 SSML；Codex 被要求逐字保留已确认文案，但模型规划仍需以消息中列出的实际分段为准。不支持声音克隆、实时对话、多人镜头或自动复杂分镜剪辑，也不提供独立试听。首次制作可先明确要求短样片，完整制作请求会交接全部计划，不固定截成五秒。

运行时为 Codex 显式加载 [口播剪辑 skill](../runtime/skills/narration-editing/SKILL.md)：通常同镜头最多连续两段，随后按内容建议切换景别、合同局部或辅助画面，在语义停顿处干净切镜并保持声音连续。这只是创作提示，不是后端硬限制；用户明确要求长镜头时仍可继续。当前单源口播计划把续接设为 `false` 只会复用原图，不等于真正切镜。需要新景别或插入画面时，先在对话中说明素材准备与合成能力，不假称已经执行，也不自动增加付费生成。

复用 OpenMontage `AzureTTS`、`TalkingHead`、`VideoTrimmer`、`FrameSampler` 和 `VideoStitch`，由现有 ComfyUI 队列上的薄节点调用隔离 SadTalker 环境，不重写生成或剪辑引擎。第一段使用指定原图；续接段提取前段实际最后一帧时间戳，再通过原生 `FrameSampler` 导出 PNG 作为下一段源图。非续接段重新使用原图。每段完成后持久保存私有清单，应用校验固定路径、原件哈希及素材来源链后导入片段和尾帧。全部片段通过原生 `VideoStitch` 合成一份 MP4，实际时长以配音为准。

对话是项目工作的入口，不是独立制作工具。结构化分段剧本保存为项目 Markdown 文件；每段文案与已完成短片直接显示在对话中，尾帧按所属片段折叠查看，原始 Codex 日志仍默认折叠。配音、等待 GPU、逐段生成、提取尾帧和拼接均显示真实阶段；片段和尾帧通过校验后立即入库并通过 SSE 更新，全部中间素材和成片齐全才标记完成。刷新、断线或已交接任务重启只恢复原任务查询，不重新调用 Codex、配音或 GPU。

每轮对话都提供当前项目的最近 8 条运行结果、分段剧本、停止状态及最近 100 个素材的受保护元数据，包括继续既有 Codex 会话时。记录只是上下文，不是重新执行旧请求的指令；候选图和附件读取权限不变，不跨项目读取。剧本和素材是持久项目成果，后续讨论可据此调整计划。停止后的任务不自动续跑，也尚不支持将旧任务片段与新任务片段自动合成，不能声称已经恢复或完成未支持的操作。

口播的“停止当前回复”先持久保存停止请求，再发送当前任务专属停止标记，不调用 ComfyUI 全局中断。执行器在下一段或拼接开始前检查；配音准备阶段也会跳过后续配音和 GPU 提交。正在执行的单段生成或拼接不能立即撤回，可能继续完成并计费，已有素材保留。确认前显示“正在停止后续步骤”，重启后可重发幂等停止标记，但绝不重提生成；若整片已经完成，保留真实完成结果。旧 Azure Speech batch avatar API 保留兼容，但不是对话口播的自动回退服务；上游固定版本的 MuseTalk 仍是占位实现。

- 原生路径需同时设置 `OPENMONTAGE_AVATAR_ENABLED=1`、`SPEECH_AVATAR_ENDPOINT` 和现有私网 `COMFYUI_SERVER_URL`，并安装 `StudioOpenMontageTalkingHead` 节点。节点委托 `/srv/openmontage-avatar/openmontage-avatar-worker.py`，使用同目录 `venv`、`openmontage` 与 `SadTalker`，不修改 ComfyUI 的 Python 环境。当前适配接受 `10.0.0.0/8` 中的私网 GPU 地址。
- 服务启用 `ProtectHome=yes` 时，隔离 `venv` 的基础 Python 也必须位于 `/srv/openmontage-avatar`，不能链接到用户主目录。子进程 `HOME` 与 `NUMBA_CACHE_DIR` 指向各自任务输出目录；保留系统只读限制。部署前须以服务账号在相同挂载沙箱中验证 `inference.py --help`，仅 SSH 登录环境验证不足。
- 本地 dev 可用 `OPENMONTAGE_PYTHON` 和 `OPENMONTAGE_ROOT` 指定隔离 Python 与已配置的 OpenMontage 目录；默认仍为容器路径。配音使用当前 Azure CLI 身份，需相应 Speech 权限。使用独立 `DATA_DIR`、`WEB_PORT`、`API_PORT` 和精确 `APP_ORIGINS`，并设置 `RUNTIME_CONFIG` 连接既有本地 Codex 网关；仅监听本机。环境文件通过 `node --env-file=<path> "$(command -v npm)" run dev` 加载。
- SadTalker 在每任务可写工作目录运行，通过符号链接复用只读原版代码和模型；原生临时合成文件不写安装目录。原片保留为 `native.mp4`，随后由 OpenMontage `VideoTrimmer` 全片转为 H.264/AAC 的 `video.mp4` 再入库。上游错误仅写入 GPU 任务私有日志，不自动重试。
- 运行时安装 FFmpeg；构建时通过受结构断言保护的认证适配，为原生 `AzureTTS` 增加短期托管身份令牌。令牌仅在配音子进程内存中传递，不写入任务账本、素材或 ComfyUI 工作流。
- 源图必须属于当前项目且哈希匹配；原件不覆盖。原生任务记录源素材及哈希，重启后查询原任务，不重新配音或重新提交 GPU。GPU 节点执行前也写一次性标记；未知状态需要人工核验。
- SadTalker 使用原生 `full` 和 `still_mode` 保留背景，默认脸部模型为 256 模式；输出画幅不代表脸部细节达到同等分辨率。尾帧续接不保证姿态、嘴形、身份细节完全无缝，需实际播放审核。

- 本地设置 `SPEECH_AVATAR_ENDPOINT=https://example-speech.cognitiveservices.azure.com`，并让已登录的 `az` 位于服务进程 `PATH`；使用 `AzureCliCredential`，不配置或保存 Speech 密钥。当前开发机还需将 `$HOME/.local/share/qwen-azure-cli/bin` 加入 PATH。未配置端点时禁止生成，不影响已有聊天功能。
- 云启动器支持同名可选变量，使用 Web App 托管身份；上线前须确认目标账户支持 batch avatar、身份具备对应 Speech 权限及网络可达。账户级 `Cognitive Services Speech User` 包含 BatchAvatar 权限；现有 OpenAI 角色不包含该权限。不要配置账户密钥或订阅级角色。
- 对话通过 `/api/projects/:id/chat` 的 Codex 决策交接任务；兼容接口 `/api/projects/:id/avatar-jobs` 仍要求显式计费确认。沿用登录、CSRF 和项目所有者校验。全局同时最多一个未结束或待核实的口播任务；提交前写 SQLite 账本，以请求 ID 和输入哈希去重，整个序列只发送一次 ComfyUI 队列请求，每段配音各一次。
- 刷新、断线和重启仅查询原任务。明确拒绝或云端生成失败正常标为失败，网络结果不明保留“待核实”，不自动重提、不更换服务。每 5 秒查询，配音阶段通过回调即时持久保存；满 24 小时停止查询并保留阻断，此时或云端任务已过期时，管理员须核查显示的任务 ID 和服务记录，再在停止后端后人工处理账本，不能直接清账重试。
- 预设服务输出只允许 HTTPS Azure Blob 地址，不向下载域名转发认证头或向前端暴露 SAS；原生输出仅从已配置私网节点的固定任务路径读取。单份成片和所有中间素材各限 64 MiB，清单限 64 KiB。使用 `ffprobe` 校验 MP4/H.264、音轨、尺寸和 10 分钟以内的正时长，成功后原子写入任务状态与项目素材索引。素材支持授权播放、Range 和下载；尾帧有缩略图，视频无独立缩略图。生成中或待核实的任务阻止删除项目。
- 云端任务保留时间设置为 24 小时；本地项目副本持续保存至用户删除项目。删除本地项目不等于删除云服务记录或备份。任务失败、停止等待或关闭页面不保证免计费，实际金额以 Azure 账单为准。

2026-09-23 本地通过一次 14 字符文案真实生成验收：1920×1080、约 3.33 秒、673939 字节。已校验音视频轨、非空与变化画面、手机浏览器播放/拖动、授权下载及 HTTP 206；仅提交一次，没有自动重试。另有离线 API/权限/恢复测试和 320/390 像素手机回归。费用尚未核算，其他人物姿态及声音组合未逐一付费测试；本地生成验收不等于生产托管身份的生成验收。

### 文件上传与附件通知

输入区回形针和素材库的“上传文件”支持多选图片、视频、文本及其他文件，单个文件最多 64 MiB，每批/每条消息最多 10 个。上传完成即写入项目素材库；从待发送附件移除只取消本次附加，不删除资料。可只发送附件，不要求额外文字；上传本身不触发模型调用。素材库可将已有资料重新附加到对话。

上传过程中显示当前文件和取消按钮，聊天、素材库及修改图片表单均可取消。取消中止当前浏览器请求及剩余批次，保留此前上传完成的文件和草稿。服务端在收到连接断开后停止后续处理或入库，清理未入库对象；若请求已完成或反向代理未及时传递断开，素材仍可能保留在项目库，取消不等于删除已完成素材。

PNG/JPEG/WebP 做真实解码、方向修正、去除元数据并归一化为 PNG，生成 WebP 缩略图，最多 4000 万像素、拒绝多帧；其他格式保留原始字节。视频使用文件签名识别 MP4/WebM/MOV/Ogg，浏览器支持对应编解码器时可以播放，支持 Range 下载；不额外转码或抽帧，上传视频使用类型图标。文本、PDF 和其他文件使用文件图标与下载，不内联执行或渲染 HTML/SVG/脚本，没有文件执行功能或恶意软件扫描。

聊天请求只提交本轮选中的附件 ID。后端验证项目归属，初始 Codex 提示词只包含文件名、类型、大小及 `/api/assets/<id>/content` 位置，不包含正文或像素，也不把整个素材库附加到消息。位置是应用内受登录保护的相对下载地址，不是公开链接、SAS 或 Codex 容器路径。附件名称和内容视为不可信数据，不作为指令，不发给 Web Search。带本轮附件时不会静默将上一张生成图替代为编辑来源。

Codex 的 shell、直接文件系统和任意写文件能力仍关闭，通过官方 MCP 协议接入受控 `studio_attachments` 工具：列出允许的附件、分页读取 UTF-8 文本、查看最长边 1024 像素的图片预览、查看视频前 600 秒内指定时刻的单帧，以及下述图片处理。文本每次最多 16000 个 UTF-16 代码单元，每轮最多 32 次附件工具调用。不解析 PDF/Office/压缩包，不执行脚本，不分析视频音轨。查看附件与编辑决策分离：上传图片可以作为单图编辑来源，但不支持图生视频。

`process_image` 使用已安装的 [Sharp/libvips](https://sharp.pixelplumbing.com/) 做本地裁剪、缩放、PNG 压缩，不开放 shell 或第三方图片服务。参数为 `assetId`、可选 `crop: {left, top, width, height}`、`maxWidth/maxHeight`、`palette` 和 `quality`；裁剪坐标按纠正方向后的原图像素计算。默认保留分辨率、无损 PNG 编码；缩放不放大，显式 `palette=true` 才进行有损调色板压缩，`quality` 仅影响调色板量化。不保证压缩后更小或达到指定字节数，返回实际尺寸、输入/输出字节数和缩放预览。每轮最多尝试 4 次，每个结果最多 16 MiB，输入/输出最多 4000 万像素；不覆盖原图。

Codex 仅在用户要求或明确授权预处理时调用。纯裁剪/压缩走 `action=chat`，不调用图片模型；Codex 对话本身仍可能计费。结果另存到素材库及当前助手消息，保留源 ID/哈希；需要继续 AI 编辑时，Codex 可明确选本轮返回的新 `assetId`。工具只能处理当前可读附件，库内其他图片须重新附加；下一轮继续处理派生图也应重新附加。示例：“把这张图中心裁成正方形，最长边缩到 1536 像素，无损 PNG 压缩，保留原图。”工具不会自动重试先前失败的模型任务。真实 MCP stdio、裁剪像素/尺寸/压缩、权限拒绝和处理图入库后继续编辑已通过离线回归；本轮未进行新的真实 Codex/图片模型调用。

每轮读取范围为本次选中的附件；本次未附加时，使用当前保留对话中最近一条带附件的用户消息，不包括整个素材库或其他项目。后端提前把允许的文件通过内部令牌保护的接口复制到 `/state/attachment-runs/<run-id>`，验证大小和 SHA-256 并封存白名单；模型只在主动调用工具后收到内容。临时副本在任务结束后删除，异常遗留目录超过一小时由清理任务删除，资料库原件保留。工具返回的内容会发送给 Codex 模型服务，并可能保留在 Codex 会话记录中；删除临时副本不等于删除模型历史。处理过程原样保留 SDK 返回的事件，可能包含附件工具参数、正文及图片载荷，沿用项目访问权限；不会额外读取环境变量或凭据。

附件 ID 随消息和重发保留；重建历史时仅恢复保留消息的附件元信息。下载继续经过既有应用登录授权、Host/Origin 检查和 no-store，普通文件强制 attachment、application/octet-stream、nosniff 与 sandbox。文件按 UUID 保存，客户端文件名不参与存储路径。当前为获授权用户共享项目，不是按用户隔离的私有空间。

### 默认参数

设置中的“默认比例”和“默认质量”只在对话未指定参数时使用。Codex 的结构化决策返回本次比例/质量及显式像素尺寸 `size`，当前要求及当前确认执行的已讨论尺寸优先于默认值；服务端校验支持范围，不偷偷换比例、像素尺寸或模型。生成与编辑均支持明确的目标尺寸，原参考图字节不变。编辑没有指定尺寸时保留来源尺寸，Azure 来源尺寸不满足输出限制时使用 `auto`，输出按实际尺寸保存，不承诺与原图完全相同。

Azure GPT-image-2 支持低/中/高质量和自定义输出尺寸：[官方约束](https://learn.microsoft.com/en-us/azure/ai-services/openai/how-to/dall-e#size)为宽高均为 16 的倍数、最长边 3840、最长宽高比 3:1、总像素 655360 至 8294400。例如 `2048x1152` 可用，`1920x1080` 不满足对齐要求，明确拒绝而不静默取整。Azure/Qwen/H3 均支持 1:1、3:2、2:3、4:3、3:4、16:9、9:16 预设比例。Qwen 自定义输出限 32 的倍数且总像素不超过 4194304；改尺寸编辑使用目标 latent，原图只作参考。GPU 质量档位是采样预算：Qwen 25/35/50 步，H3 20/30/40 步；H3 仍为固定比例预设、124 帧，非长视频或自定义像素输出。尺寸、原始 Process 和 iPhone 输入定位修复已随 `20260922-fixes-cb8bbe8` 发布，自定义尺寸路径通过离线测试但尚未新增真实生成验证。

项目列表每行的删除图标会打开确认。删除项目、对话、任务和素材索引；清理原图/视频及缩略图，失败项写入 SQLite 待清理表，下次启动或删除时重试。活动/排队任务和过时确认会拒绝删除；其他打开页面收到 SSE 删除事件后切换项目。运行时检查点、Codex 会话和已有备份不在此次清理范围，不应将此操作视为全系统隐私擦除。

### VM 管理

支持最多 20 台 VM 的共享配置：在面板选择实例，管理员可新增和修改配置名称、订阅 ID、资源组、VM 名称及 ComfyUI 私网地址。配置与操作账本持久保存，旧单 VM 文件在启动时自动迁移；原操作账本保留，并按 Azure 资源标识隔离恢复。配置保存及电源确认均检查配置版本，过期页面需刷新后重新确认；存在未结束 VM 操作或应用任务时拒绝修改配置。失效实例仍显示资源标识并可编辑，Azure 404 与 403 分别提示资源不存在及权限不足。

只有 `ENTRA_ADMIN_USER_IDS` 中的管理员能修改共享配置；普通本地账号和非管理员 Entra 用户可选择、查看并执行原有电源操作。无认证的本地开发环境允许编辑。Azure IAM 授权不在界面中提供，新增配置不会自动创建资源或授予角色；身份认证方式和 CLI 路径只能由服务器配置，不能通过 API 修改。界面新增地址仅接受 RFC1918 私网 IPv4 的 HTTP(S) 源地址，不含路径、凭据或查询参数，探测不跟随重定向。

面板的实例选择仅决定状态和电源管理目标，不改变生成后端的 `COMFYUI_SERVER_URL`；生成路由仍由部署环境配置。更换生成 GPU 需要另外确认模型、私网连通性并更新该环境变量。配置文件首次不存在时可在界面添加，设置 `DATA_DIR` 且未设置 `VM_CONFIG` 时使用该数据目录下的 `vm-config.json`。

右上角 CPU 图标打开“VM 管理”，与设置并列，不再占用项目菜单。面板分列电源、ComfyUI 和计算计费状态，支持刷新；主操作随状态切换为启动或关闭并解除分配，重启单独显示。全部动作要求确认；解除分配停止计算资源计费，但磁盘继续计费。执行中、结果待核实或状态读取失败时禁止新操作，刷新不清除操作错误。没有定时任务、空闲自动关机、随生成自动启动或 Spot 自动重试。

服务端仅操作已保存配置指向的 VM；电源操作必须指定配置 ID 和当前版本，不能直接提交任意 Azure 资源 ID。CLI/托管身份 token 不传给浏览器。应用存在活动或排队任务时拒绝管理操作；GPU 队列非空时禁止关闭/重启，队列读取失败时必须额外确认中断风险。已提交动作异步追踪、持久化并按请求 ID 去重；重启后继续查询，不重发 Azure 请求。Azure 明确拒绝（包括已知容量不足错误）或异步操作明确失败后保留原因并解除操作锁；界面自动核实结果，下一次确认使用新请求 ID，也可以取消此次确认。状态请求最长等待 15 秒，提交请求最长等待 30 秒；超时不等于云端取消，不自动重试。

网络结果不明时标记“待核实”，继续查询原异步操作；无异步地址时，仅依据目标电源状态确认启动/解除分配完成，或依据不早于本次提交的 provisioning 失败时间确认失败。仅看到 VM 停止、旧失败或读取异常不能解锁。若仍无可靠结论，继续阻止新操作，需管理员核查 Azure 活动日志后，在停止后端的情况下人工处理操作账本；本功能不提供撤回已提交 Azure 启停请求的虚假取消按钮。

仅支持单后端实例。测试环境的 `DATA_DIR` 隔离配置与操作账本，没有配置时不会调用 Azure。云端需使用 `/home/` 下的持久配置路径；`HOSTING_MODE=appservice` 新增配置默认使用托管身份。所有通过应用登录授权的用户都可控制已配置 VM，不再使用独立 `VM_ADMIN_USER_IDS`；配置新增和修改额外要求管理员身份，匿名及未授权用户仍被拒绝。

2026-09-22 已按用户授权，为当前部署 Web App 的系统托管身份分配并回读两个自定义角色：目标 VM 范围的 `Qwen Studio VM Power Operator`（virtualMachines/read、instanceView/read、start/action、restart/action、deallocate/action），以及 GPU 资源组范围的 `Qwen Studio VM Operation Reader`（仅 Microsoft.Compute/locations/operations/read）。后者用于 Azure 异步完成状态查询，不授予资源组其他 VM 的电源操作、资源写入或权限管理能力。

本轮只变更上述 Azure RBAC，没有发布新镜像、启用云端 VM 配置或扩展 Web App 至 GPU 的私网连接。私网仍是云端 ComfyUI 就绪/队列查询和 GPU 生成的前置条件。真实状态读取已在本地验证，启停仅通过 mock/API/浏览器测试，没有为验收启动收费 VM；云端托管身份实际操作仍待发布后验证。

### 本地 GPU 接入

普通多镜头故事也由对话驱动：Codex 在 `video` 决策中提供 `storyPlan`（标题及 2–12 段剧情/提示词），应用保存分镜 Markdown 文件，再逐段调用既有 MiniMax H3 适配器。每段完成即入库并显示在对话中；全部完成后复用原生 `VideoStitch` 拼接，再使用同一原生工具的归一化方法固定输出尺寸及 24fps，处理 AAC 拼接边界时间戳。约 40 秒计划通常为 8 段，原始视频帧总长约 41.33 秒，最终时长以校验结果为准，不自动裁成精确 40 秒。手机竖屏为 576×1024，不声称 1080p 或 2K。不同段为独立文字生成，重复外观提示不能保证人物完全一致，也不提供统一配乐、字幕或精确台词。

故事任务使用稳定片段 ID、原生检查点和本次计划顺序校验，禁止自动重复提交。停止会保留当前已提交段的结果，在下一段或拼接前结束；执行中的拼接可继续完成。应用重启后查询同一运行，运行时重启则明确标为结果待核实，不重跑 GPU。已完成片段保留，尚不支持将旧任务与新任务片段自动续接成片。单段及成片上限 48 MiB，分段总量超过 96 MiB 时不继续后续工作。后续对话会收到项目已保存的分镜概要、素材与执行状态。

新增模型选择及 GPU 工具已在本地验收，尚未发布到云端。右上角设置分别选择图片模型（默认 Azure image2，可选 Qwen Image 2.1）和视频模型（默认不启用，可选 MiniMax H3）。Codex 继续根据对话决定是否调用工具，不能自行改选模型；模型不可用时失败，不回退到其他服务。选择随请求持久化，重新发送保留该条请求的模型。

在仓库根目录将 `COMFYUI_SERVER_URL` 设置为已授权的私网 ComfyUI URL，再运行 `docker compose up -d --build runtime`。不要将 ComfyUI 暴露到公网。容器重建时需要再次提供该变量，普通容器重启会保留配置。云端启动器支持同名可选环境变量，但现有 Web App 尚未配置 GPU 私网路径，本轮未修改云资源。

ComfyUI 原生节点需支持 Qwen Image 2.1 与 MiniMax H3。固定文件名见 [GPU 工具](../runtime/comfy_media.py)，所有权重位于 GPU 持久数据盘。健康接口检查节点与文件名，不代表实时生成一定成功；Spot 驱逐、GPU 忙或缺文件均可能导致任务失败。

- Qwen Image 2.1：BF16 权重，单张生成；1:1 / 3:2 / 2:3 对应 1024×1024 / 1536×1024 / 1024×1536。Codex 可从候选中选择上传图或保留生成图编辑，优先使用明确目标尺寸，否则沿用原尺寸；校验来源哈希并另存新图。动态图片输入使用 ComfyUI v3 的 `images.image_1`。新选图协议已本地验证；GPU 路径未在本轮实际生成。
- MiniMax H3：BF16 推理权重，默认 20 步，单段 124 帧，24fps，约 5.17 秒双声道 MP4，可通过上述故事流程生成多段再拼接。当前精确画幅：1:1 为 640×640、3:2 为 768×512、4:3 为 768×576、16:9 为 1024×576，竖向交换宽高；此前验收视频 832×480 属于旧预设。不是完整托管版 2K 流水线，不支持上传参考视频或任意已有视频编辑。
- OpenMontage 保存原生检查点；提交前写入任务账本，记录 ComfyUI prompt ID，结果校验后入库。GPU 忙时不提交，不自动重试。普通单图/单片停止仅中止等待，已提交 GPU 任务可能继续运行，重试前必须核查；多段故事使用上述步骤边界停止，已完成段继续入库。
- 视频可在对话和素材库播放、下载；后端支持 MP4 MIME、单段 HTTP Range 与缩略图，云端存储实现也支持 MP4，但云端端到端未验收。
- Qwen 仅用于研究评估；H3 本轮限已确认符合社区许可的非商业测试，存在地域限制。向第三方开放前须另行核查许可、访问控制和使用条款。GPU 运行时间、磁盘和 Codex 调用可能计费。


| 用途 | Foundry 账户 / 部署 | 区域与认证 |
| --- | --- | --- |
| Codex 决策 | `example-gpt-account` / `gpt-5.4` | southeastasia，服务端 API key |
| 图片工具 | `example-image-account` / `gpt-image-2` | eastus2，Entra token |

图片账户保持 `disableLocalAuth=true`，未开启密钥认证。自动识别和显式图片请求在提交前，后端通过 `$HOME/.local/share/qwen-azure-cli/bin/az` 获取短期 Cognitive Services token，只经内存传给工具，不写入会话或检查点。自动识别时获取 token 失败仍可对话，但图片动作会在调用图片 API 前报错。登录过期需在本机 Azure CLI 重新登录；不在聊天中输入密码或 token。Codex 不接收图片 token，没有 shell、任意写文件或自行安装工具的权限；受控 MCP 处理结果由应用保存。

Web Search 随固定版本 Codex CLI 一起安装，运行时设为 `webSearchMode: 'live'`，不是额外的浏览器或第三方搜索插件。保留 `shell_tool=false`、`apply_patch_freeform=false`、只读沙箱及 `approvalPolicy=never`，不新增 MCP、Skill 安装或系统网络执行权限。指令要求引用实际查阅的 HTTPS 来源、将网页视为不可信数据、不把凭证或私人历史作为搜索词；这是模型行为约束，不是独立的数据防泄露过滤器。

2026-09-22 本地真实搜索 Microsoft Edge PWA 文档成功，收到三条已完成的 SDK `web_search` 事件，回复包含 Microsoft 官方来源，未生成图片。事件在“处理过程”中显示；已随 `20260922-web-search-dc11780` 发布，云端托管身份下搜索未验收。仓库根目录可手动运行 `WEB_SEARCH_TEST=1 node runtime/smoke.mjs`：必须有搜索完成事件、来源链接且无图片才通过，禁止与出图验收开关混用。该测试调用真实模型/搜索，可能计费，不属于默认离线测试。

每个项目复用一个 Codex thread，SQLite 保存 thread ID、消息和运行状态；Codex 自身会话、运行结果及 OpenMontage 检查点保存在 Docker 命名卷 `qwen-studio_runtime-state`。图片工具继承上游 `BaseTool`，返回 `ToolResult` 并写入标准 `asset_manifest` 检查点，不是完整 OpenMontage 视频流水线。上游源码位于容器 `/opt/openmontage`，遵循其 AGPL-3.0 许可，分发或提供网络服务前需评估对应义务。

手机端统一提交 `auto`，由 Codex 结合会话输出结构化的对话、图片或视频意图，不再手动选择模式。指令要求只有明确要求现在出图才执行图片工具，讨论、编写提示词和否定出图应仅对话，意图不清时先询问；模型判断并非绝对可靠，也不替代审批。视频尚未接入，返回明确说明且不以图片替代。API 保留显式 `chat`（禁止图片工具）和 `image` 模式。图片固定 `n=1`、`quality=low`，1:1 / 3:2 / 2:3 分别输出 1024×1024 / 1536×1024 / 1024×1536。全局串行、最多 10 条待处理，不自动重试或更换服务。GPT 和图片均可能收费，金额未核算，不把未知费用显示为零，应以 Azure 账单为准。停止请求不保证撤回已送达 Azure 的调用。

已实际验证：文字回复、同项目上下文、1024×1024 PNG 回收及 OpenMontage 检查点、空闲容器重启后同一 thread 恢复，以及 `auto` 下构图讨论仅对话、视频请求明确拒绝且无图片。自动图片决策通过离线测试，未再次真实出图；另外两种尺寸尚未实际计费验证。`node runtime/smoke.mjs` 是手动付费验收脚本，不属于默认测试；`IMAGE_TEST=1` 会请求一张真实图片，`AUTO_TEST=1` 允许自动判断并可能出图，不要把它们加入自动测试。`NO_IMAGE=1` 仅事后断言，不能阻止调用或费用。

## 已实现

已随 `20260922-web-search-dc11780` 发布：Codex 可决定 `edit`，仅编辑保留对话中本轮之前最近一张已完成生成图。工具读取存储中的原始 PNG，通过 Azure multipart 编辑接口上传；输出另存为新素材，记录来源 ID/哈希并保留原尺寸。清理掉的重发分支图片即使仍在素材库也不会被选中。Codex 只接收来源元数据，原始像素只交给图片工具；无原图时澄清，不静默重新生成。对话按轮次排列，时间左置，重发/复制右置，出图和修改均显示持续加载状态。

后续改动已随 `20260922-assets-96762a2` 发布，移除“后端固定选上一张图”：Codex 同时决定 `action=image/edit/chat/video` 与 `sourceAssetId`。编辑必须指定候选素材 ID；生成新图必须为 null，不因有附件或已有图片而自动变成编辑。候选仅包含当前消息附件和保留对话中的上传图、已完成生成图，按首次出现顺序提供名称、尺寸及关联消息，不默认选任何一张。重发清理的分支、未来消息、未附加的资料库图片、其他项目及非图片不在候选中；库内图片需重新附加才能被引用。目标不明确时由 Codex 澄清，不静默替换原图或回退生成。

后端先发送候选元数据，Codex 选定后运行时通过 `needsSource/sourceAssetId` 请求对应原图；应用再次检查范围、大小、SHA-256，再通过内部令牌保护的 `/runs/:id/source` 传送原始 PNG。运行时复核 ID、哈希与尺寸后才调用现有编辑工具，保存来源链和新素材，保留原件。原图交付等待最多 60 秒并支持取消；没有自动付费重试。一次编辑只支持一张原图：Azure 原图必须小于 50,000,000 字节，Qwen 仍最多 32 MiB；超限会在调用图片接口前明确失败，可另行要求 Codex 缩放/压缩。已回归验证 38.8 MB 原图及其超过 48 MiB 的 base64 HTTP 请求，修复先前上传允许而编辑交付失败的问题。输出尺寸规则见上方“默认参数”，不再以旧三个输出尺寸限制上传原图。此前真实 Azure 双图上传测试已确认 Codex 选择第一张而非最后一张，按要求修改颜色，两份原件哈希不变；本轮修改未新增真实模型调用。

2026-09-22 本地真实生成后编辑已验证蓝杯变红杯、同一 thread、1024×1024、原图字节不变。生成阶段曾因新增检查点字段不兼容而在出图后失败，修复并离线恢复原图后仅执行一次编辑；无重复生成，详细记录见部署文档。手动 `EDIT_TEST=1 node runtime/smoke.mjs`（仓库根目录）会收费生成及编辑各一张，不进入自动测试；`PROJECT_ID` 与 `GENERATION_RUN_ID` 可指定已完成且已导入的原图，只执行编辑。云端托管身份编辑未验收。

## 数据与边界

默认数据目录为当前工作目录下的 `.data/`，可通过 `DATA_DIR` 改写。数据库是 `studio.sqlite`，图片在 `images/`，默认不进入版本控制。浏览器只缓存选中的项目 ID，业务数据位于后端。

备份时先停止应用和容器，再复制整个数据目录及 `qwen-studio_runtime-state` 命名卷，避免遗漏 SQLite WAL、图片及 Codex 会话；凭证单独安全保管。不要执行 `docker compose down -v`，它会删除运行时历史。删除应用数据目录会丢失全部项目。测试使用系统临时目录，截图和 trace 在 `test-results/`，不写入日常数据目录。

当前仅有本机 Host/Origin 检查，**没有用户认证，不是可公开部署的服务**。本机可访问 API 的进程可以读取全部项目；前端开发服务器和 `vite preview` 也不是生产部署方案。`npm run build` 只产出前端静态文件，不打包后端；`npm run preview` 不提供完整 API。

当前支持文字、附件元信息通知、按需附件读取、受控图片裁剪/缩放/压缩及 Codex 自主选择原图编辑；上传文件可以入库、预览或下载，初始提示词只接收附件及候选元信息，内容经读取工具或执行编辑按需传输。尚未实现 PDF/Office 内容解析、多图合成/蒙版、完整视频剪辑流水线/审批/预算治理、完整素材版本管理、新建或重置 thread 的 UI、用户配额及大规模分页。生产 Entra/HTTPS/PWA 仅适用于云端入口。图片处理及大图交付修复已随 `20260922-image-tools-7f98728` 发布，云端 Codex 自主调用新工具的端到端验证仍待实际使用；测试未触发真实模型调用。

进行中的调用在后端/容器重启或连接结果不明时标为“结果待核实”，不会自动重发。当前没有中断结果自动对账导入功能；远端可能已完成并计费，需要人工检查运行记录和检查点后再决定下一步。已完成会话的重启恢复通过，不代表执行中断能无损恢复。

GPU 历史事项见 [临时交接文档](../docs/TEMP-azure-handoff.md)，最新状态以上面的本地 GPU 接入说明为准。模型许可限制继续适用，不能把“非收费”自动视为允许的使用。
